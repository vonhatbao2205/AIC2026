## Pink TypeSafe replacement

At the user's request, both Jev blocks now use `typesafe-pink.png`: the black
TypeSafe mark on a solid pink square, matching the supplied visual reference.
Downloaded unchanged from the official homepage's icon asset:
[400×400 PNG](https://framerusercontent.com/images/kcuF2BEp5XaVfkmFB634IPRKQH0.png),
linked by [TypeSafe AI](https://typesafe.ai/). The earlier monochrome SVG/PDF is
retained for provenance but is no longer used in Fig. 1.

## Architecture symbols

Functional pictograms use the existing LaTeX `fontawesome5` package: database,
film, query, search, layers, desktop, clipboard, shield, document, tools, clock,
check, continuation and hourglass. They are vector font glyphs, colour-coded
by processing layer; numbered stage badges are native TikZ circles. Provider
logos remain unchanged.
